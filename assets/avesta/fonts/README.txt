Fonts served by avesta.solutions
================================

Fraunces  — SIL Open Font License 1.1 — see LICENSE-Fraunces.txt
Manrope   — SIL Open Font License 1.1 — see LICENSE-Manrope.txt

Both are variable fonts, latin subset, taken unmodified from the Fontsource
packages @fontsource-variable/fraunces@5.3.0 and @fontsource-variable/manrope@5.3.0.

They are self-hosted rather than loaded from fonts.googleapis.com so that a
first visit costs one connection to this server instead of two to Google's,
and so the pages keep their typography when Google is slow or blocked. The
Hostinger CDN caches them for a week, so the cost below is paid once.

  fraunces-normal.woff2   35.8 KB   headings
  manrope.woff2           24.3 KB   body text

The italic was dropped on 28 November 2026: 44.6 KB of a 105 KB set, for one
line of each heading. The emphasised line is now set in the roman at a heavier
weight, in the second brand colour, over the gold rule it already had.

Subsetting them further was tried and abandoned: re-compressing the Fontsource
latin files made them larger, not smaller.

PRIVATE STATE / IMPORTANT HOSTING REQUIREMENTS
The first enabled authentication request attempts to create this new directory:
  <domain directory>/avesta-stage7b-private-b72b038b5177/
It is a sibling of public_html, NOT a child of it. The PHP worker must be able to create
it with mode 0700 and private files with mode 0600. The lab verifies its documented folder
layout and a server-supplied HTTPS flag. It does not implicitly trust forwarded headers.

move runtime files into public_html, copy a production store or enable local_test.

WHY THE PORTAL IS DIFFERENT FROM THE OLD DEMO
PHP chooses the Customer/Staff/Administrator/Super Administrator experience from the current
account, validates immutable identity/active/role/version/expiry, and authorizes records before
rendering. No complete unfiltered record set is embedded in portal JavaScript. Real user
accounts and production policy have not been imported. The browser role-selector demonstration
remains in the earlier Stage 6 site only; it is not a login and is not shipped as the active portal.
The original Stage 7A records contain no balances, dates or payment ledger, so none are invented.

PAUSE / RETURN
Sign out where possible. Setting enabled=false pauses authentication only; public demos still run.
Alternatively, the separate Stage 7B Pause ZIP contains only avesta-integrated-stage7b/PAUSED.flag.
Extracting that ZIP into public_html/staging/ pauses all Stage 7B PHP entry points. It leaves
static assets protected by the parent Hostinger rules. Do not install pause and update together.
Neither mechanism deletes private data nor irrevocably revokes existing session files; resuming
before expiry may restore a still-valid session. For definitive retirement, keep paused and ask
hosting staff to clean up only this exact instance's private session/state directory after
preserving required test evidence. Do not delete shared or production files.
The lab lifetime is 7 days from provisioning, with 15-minute idle / 2-hour session limits.
Earlier Stage 6 and Stage 7A can be reopened at their original addresses; neither is overwritten.
This pause switch is NOT a full filesystem/database backup or rollback.
